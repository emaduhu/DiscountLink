# DiscountLink 1.0.34

- Restored saved sessions when returning to the app after backgrounding or app recreation, preventing unnecessary splash and login restarts.
- Restored the selected home page so buyers, sellers, and deliverers return to the page they were using.
- Kept users signed in across app restarts until they explicitly press the logout button.
- Added product-added FCM notifications with product metadata and product-detail deeplink routing when a user taps the notification.
- Added an authenticated product-detail endpoint for notification taps and shared product openings.
- Added password creation for Google social registration so Google-created users can also sign in later with email or phone number and password.
- Added seller product discount type selection for percentage-off or fixed-amount-off pricing.
- Fixed fixed-amount discounts so a TZS 200 discount on a TZS 1,000 product creates a TZS 800 product price.
- Improved phone login normalization so Tanzanian local numbers, `255...`, and `+255...` formats resolve consistently.
- Added show/hide password controls on login and registration.
- Prepared real app screenshot assets for Google Play and the App Store across phone and tablet sizes, including splash and login images.
- Prepared a cPanel backend deployment archive for the v1.0.34 API changes.
