# DiscountLink 1.0.36

- Allowed seller accounts to also shop the marketplace from a new seller Shop tab.
- Allowed sellers to add marketplace products to cart, checkout, view buyer orders, and rate products without creating a separate buyer account.
- Expanded automatic product-added FCM notifications to every active user account with a registered push token.
- Kept product-added notification taps routed to the product-detail page for the announced product.
- Updated Google Play and App Store phone/tablet assets to show seller marketplace access, fixed-amount discounts, active orders, delivery tracking, secure chat, splash, and login screens.
- Bumped Android release metadata to version `1.0.36+42`.
